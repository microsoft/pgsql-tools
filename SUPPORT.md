# Support

## How to file issues and get help

This project uses GitHub Issues from the related project [PostgreSQL for VS Code](https://github.com/microsoft/vscode-pgsql)
to track bugs and feature requests. Please search the existing issues before
filing new issues to avoid duplicates. For new issues, file your bug or feature
request as a new Issue.

Use the following links to search for existing issues or file a new issue:

- [Search existing issues](https://github.com/microsoft/vscode-pgsql/issues)
- [File a new issue](https://github.com/microsoft/vscode-pgsql/issues/new)

For help and questions about using this project, please use the [GitHub
Discussions](https://github.com/microsoft/vscode-pgsql/discussions) associated
with the PostgreSQL for VS Code repository.

## Microsoft Support Policy

Support for this product is limited to the resources listed above.
